# 📊 Student Performance Analysis

This project analyzes student performance data using data analysis and visualization techniques. It helps in understanding how various factors such as study time, parental education, and lifestyle affect students' academic results.

---

## 🚀 Features
- Data cleaning and preprocessing  
- Data visualization using graphs and charts  
- Analysis of factors affecting student performance  
- Insights and conclusions from data  

---

## 🛠️ Technologies Used
- Python  
- Pandas  
- NumPy  
- Matplotlib / Seaborn  
- Jupyter Notebook  

---

Student-performance/

## ⚙️ Installation & Setup

Clone the repository:
git clone https://github.com/kratika630/Student-performance-.git

Go to project folder:
cd Student-performance-

Create virtual environment (optional):
python -m venv venv

Activate environment:
venv\Scripts\activate

Install dependencies:
pip install -r requirements.txt

---

## ▶️ How to Run

Run Python file:
python main.py

OR open notebook
